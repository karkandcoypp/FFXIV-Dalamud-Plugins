# CraftProfile 0.1.0

Automatic local profession profiles: all 11 profession levels, gearsets with materia,
observed stats/buffs, specialist assignments, recipe/action/book gates and loaded inventory.
Russian/English UI; /craftprofile. No network upload or gameplay automation.

Exported JSON is consumed by Craft Profit Scanner for character requirement annotations.
Unknown storage and HQ reliability remain explicitly unknown. Install, collect GSM/WVR
observations and verify in-game values before trusting a crafting rotation.
