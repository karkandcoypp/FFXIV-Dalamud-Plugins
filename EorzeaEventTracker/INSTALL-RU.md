# Eorzea Event Tracker v0.3.0 — установка

1. Если установлена тестовая DLL через Dev Plugin Locations, отключите эту копию и удалите её путь.
2. Откройте `/xlsettings` → Experimental → Custom Plugin Repositories.
3. Добавьте адрес:

```text
https://raw.githubusercontent.com/karkandcoypp/FFXIV-Ultrawide-Cutscenes/main/pluginmaster.json
```

4. Сохраните настройки и откройте `/xlplugins`.
5. Найдите **Eorzea Event Tracker**, установите и включите его.
6. Выполните `/events`.

Для русского интерфейса выберите Settings → Language → Русский. Настройка применяется сразу и сохраняется. Названия предметов и квестов переводятся, если перевод добавлен в ленту; исходное название предмета можно увидеть в подсказке.

Если этот репозиторий уже добавлен для Ultrawide Cutscenes, второй раз добавлять адрес не нужно — обновите список плагинов.

## Что проверить

Если плагин уже установлен из репозитория, нажмите Update в `/xlplugins`. Через несколько секунд после входа появятся автоматические статусы текущего персонажа.

На 18 октября 2026 года в ленте два активных события: All Saints' Wake и Fall Guys. Выберите событие слева. На вкладке Your progress показаны выполненные квесты и карточки наград с игровыми иконками, ценами и прогрессом. How to join содержит условия и инструкции.

Проверьте квесты, которые персонаж уже выполнил, известных маунтов/миньонов и вещи в сумке. Переключитесь на другого персонажа: прогресс должен измениться. После получения предмета подождите 1–2 секунды. Open on login включает автоматическое открытие окна.

Unlocked — коллекция открыта; In bags / equipped — предмет найден; Earned from quest — гарантированная награда за выполненный квест; Previously obtained — предмет обнаруживался ранее. Not detected означает отсутствие подтверждения: ретейнеры, жильё, гламурный комод и армуар не сканируются. История обнаружений хранится отдельно для каждого персонажа на этом компьютере.

Лента обновляется по HTTPS при входе, по кнопке «Обновить» и каждые 30 минут в игре. Сборщик на GitHub запускается дважды в сутки. После однократной установки 0.3.0 новые квесты, награды, картинки и переводы могут приходить через ленту без обновления DLL. Для этого нужно добавить проверенные данные события в источник ленты; сам сборщик не гарантирует извлечение всех деталей с любого сайта. Изменения API игры и новые механики отслеживания по-прежнему могут требовать обновления плагина.

Изображения скачиваются при открытии события и сохраняются в кэше. Без сети доступны сохранённые данные и уже скачанные картинки. Новую онлайн-ленту версии 0.3.0 ещё нужно проверить в игре.

При ошибке загрузки сохраните сообщение из `/xllog`.

## Установка DLL вручную

Распакуйте ZIP из GitHub Release в постоянную папку. Оставьте DLL, манифест JSON, deps.json и events.json рядом. Добавьте полный путь к DLL в `/xlsettings` → Experimental → Dev Plugin Locations и включите плагин через `/xlplugins` → Dev Tools → Installed Dev Plugins.
