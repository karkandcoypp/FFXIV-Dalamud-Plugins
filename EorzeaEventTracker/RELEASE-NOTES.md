Eorzea Event Tracker v0.1.2 for Dalamud API 15.

- Current All Saints' Wake and Fall Guys events include requirements, starting NPCs, participation steps and rewards checked against official Lodestone sources.
- Fall Guys rewards include MGF prices.
- Long reward and instruction lines wrap in the window.
- Official event feed snapshot is bundled; the hosted feed is configured by default and refreshes on login or with Refresh.
- Includes fixes for ImGui compatibility, malformed feed data, login reminders and unloading during a network request.

Install from the existing custom repository:
https://raw.githubusercontent.com/karkandcoypp/FFXIV-Ultrawide-Cutscenes/main/pluginmaster.json

Open `/xlplugins`, find Eorzea Event Tracker, install it, then use `/events`.
Disable the old development copy before installing this version. Completion remains manual; in-game behavior requires user testing.
