# Eorzea Event Tracker 0.23.0

- Stronger visual hierarchy: quest names use larger warm-gold headings; completed quest names use a softer green. Prerequisite titles receive the same treatment.
- Quest statuses are compact tinted badges with readable text, retaining distinct completed, unfinished, locked and unknown states.
- Next step is a responsive framed callout. Action labels and prominent quest names, levels, class requirements, reward targets and currency amounts are separated from explanatory text.
- NPC names use a soft blue accent with secondary location/coordinate lines in navigation, participation guides and prerequisite details.
- Section headings have subtle divider rules. Wrapping and panel heights follow actual content and the selected UI scale; no fixed-height quest panels or extra scrolling areas were introduced.
- Existing progress, filters, discovery state and reward actions are unchanged. Previous releases remain available for rollback.

Validation: Release build with warnings as errors and existing client/collector regression checks. In-game appearance still requires player verification.
