# Интерфейс 0.2.0

Референсы, просмотренные при переработке:

- [FFXIV Game Manual — Duty List](https://na.finalfantasyxiv.com/game_manual/view/): игра связывает имя квеста с журналом, а цель — с картой. Принцип для Compass: активность → квест → место и одно главное действие.
- [Simple Tweaks](https://github.com/Caraxi/SimpleTweaksPlugin): пример организации большого набора функций плагина; навигация отделена от содержимого выбранного пункта.
- [VanillaPlus](https://github.com/MidoriKami/VanillaPlus): ориентир на привычное поведение окон FFXIV. Compass остаётся обычным окном Dalamud/ImGui, а не нативным игровым аддоном.

Решения по скриншоту пользователя:

- Непрозрачные панели вместо просвечивающей сцены.
- Постоянная боковая навигация вместо радио-переключателей среди фильтров.
- В строке активности три уровня информации: название, категория/уровень, короткий статус или препятствие.
- Карточка начинается с действия, затем идут квест, NPC и большая кнопка карты.
- Для неподходящей профессии показаны реальные подходящие классы и их уровни, а не только сообщение «нужен другой класс».
- Технические поля, источник связи и объяснения алгоритма скрыты по умолчанию.
- Выполненные требования отмечены `[+]`, невыполненные — `[ ]`.
- Выбор всегда принадлежит видимому списку: смена фильтра больше не оставляет несвязанную карточку справа.
- Настройки открываются отдельным разделом, не раздвигая каталог.

Проверки: Release-сборка с предупреждениями как ошибками, алгоритмические проверки и регрессия выбора при изменении фильтров. Визуальная проверка переработанного окна в запущенной игре ещё нужна.
