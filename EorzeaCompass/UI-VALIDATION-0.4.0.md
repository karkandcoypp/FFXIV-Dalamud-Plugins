# Проверки Eorzea Compass 0.4.0

19 октября 2026. .NET 10 / Dalamud API 15.

## Прогресс и данные

879 проверок с установленными игровыми sqpack: 220 валидных определений цепочек, каждый финальный ID/название/JournalGenre, начальное состояние и доказательство завершения. 5373 именованных квеста, 356 боевых активностей (251 стандартная). 3828 записей наград: 1128 обязательных и 2700 вариантов на выбор; это записи источник–предмет, не количество уникальных вещей.

Проверены отдельные дополнения классов/профессий, четыре достижения сценария Eureka с точным названием, отличие открытия зоны от завершения, незагруженные достижения, восстановление повторяемого этапа только по потомку, отсутствие ложного доказательства от AND-соседа. Условия Unknown7 продолжают помечать доступность как неподтверждённую, сохраняя известный AND/OR-граф.

Атлас исключает нетипизированные значения, не-Item и нулевые количества сценарных наград. Выполнение квеста с выбором не подтверждает получение каждого варианта. Проверена конкретная обязательная награда Anima (Item 17530 / Quest 67934). Данные взяты из установленной игры независимо от xivtodo.

## Отрисовка

21 сценарий, каждый по три кадра производственных методов ImGui: обычное окно 1180×760, минимальное 960×600, увеличенный шрифт 22 при 1440×900, длинное имя, принятый квест, другой класс, английский язык; обзор в трёх размерах; незавершённая/завершённая/неизвестная история, общество, реликт, Eureka; атлас в трёх размерах и награда на выбор.

Изображения производственных панелей отрисованы через ImGui и просмотрены вручную. Основные карточки проходят проверки вертикального размещения; длинные списки и обзор прокручиваются. Персонаж и координаты NPC тестовые. Ввод и фильтры на этом стенде заменены статическими элементами; игровые текстуры не подключаются. Это не скриншоты из FFXIV и не проверка интерактивного ввода или карты в игре.

## Сборка и публикация

Release с `--warnaserror`: ноль ошибок и предупреждений. Локально NuGetAudit=false из-за ограничений сетевого аудита; в CI аудит не отключён. Три теста общего publisher проходят: чужие записи сохраняются, обновление идемпотентно. Первоначальный запуск Python в sandbox не смог использовать временную папку; повтор с обычным доступом прошёл.

В запущенной FFXIV проверки не выполнялись. Требуется проверить реального персонажа, загрузку достижений, иконки, ввод/фильтры, переходы к цепочке и карте. Репутация обществ, все экземпляры реликтов, vendor rewards и случайные трофеи не заявлены как проверенные или реализованные.
