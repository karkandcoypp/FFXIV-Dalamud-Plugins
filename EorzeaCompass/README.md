# Eorzea Compass — 0.3.0

Журнал прогресса персонажа для Dalamud API 15. Команда `/compass`.

## Разделы

- **Обзор дополнений**: карточки ARR–Dawntrail. Отдельно показаны завершённые истории каталога, открытые активности и первые прохождения. Общего процента «вся игра пройдена» нет.
- **Сюжетные цепочки**: основной сюжет, рейдовые истории и Hildibrand; поиск, дополнение, тип истории и состояние. В карточке — прогресс маршрута, ближайший квест, NPC и карта, задания цепочки, связанные активности и точное условие завершения.
- **Активности**: подземелья, триалы, обычные и альянс-рейды. Не открыто, открыто и пройдено — разные состояния. Сложные версии включаются отдельно, не входят в сводку обычного контента.

Структура вдохновлена [XIV ToDo](https://xivtodo.com/questlines/). Код и база xivtodo не перенесены: определения сюжетных линий составлены независимо по установленной игровой таблице Quest.

## Что считается завершённым

В `config/stories.json` записаны **37 явных правил**: 15 этапов основного сюжета, 17 линий Chronicles и 5 линий Hildibrand. Завершение подтверждается выполнением конкретного финального квеста с проверкой ID, английского названия и JournalGenre. В частности, Ivalice заканчивается The City of Lost Angels, а дополнительные кулинарные задания не меняют этот статус; Crystal Tower — The Light of Hope.

Процент истории относится к маршруту до указанного финального задания. Взаимоисключающие ветки не суммируются: используется ветка с фактическим прогрессом персонажа. Выполненный финальный квест является прямым доказательством завершения. Открытие или прохождение рейда само по себе не завершает историю. Для продолжающихся линий Dawntrail показано «Пройден текущий этап»; новые главы требуют обновления каталога.

Это каталог перечисленных историй, не всех побочных заданий игры. Общества, реликты, профессии и исследовательские зоны пока не включены в сюжетный журнал. Если финальный квест отсутствует, изменился или данные персонажа недоступны, показывается «Нет данных», а не ложное завершение.

Состояние «В процессе» использует принятые и выполненные квесты внутри маршрута и историю, раздельную для персонажей. Общий MSQ-предшественник не означает, что побочная история начата. История отменённых до установки квестов может отсутствовать.

## Данные активностей

Каталог строится из ContentFinderCondition и Quest установленной игры. Открытие читается через `IUnlockState.IsInstanceContentUnlocked`, первый клир — через `UIState.IsInstanceContentCompleted`. Достижения не требуются. Награды и коллекции не входят в процент прохождения.

Квестовая связь определяется по InstanceContentUnlock и сценарным параметрам INSTANCEDUNGEON. Неоднозначные связи отмечаются явно. Следующий шаг учитывает текущий класс/уровень, AND/OR-предшественников и принятые задания; дополнительные неподтверждённые условия не считаются доступностью. Для принятого квеста следует использовать игровой журнал, для непринятого — проверенную точку выдачи NPC.

При входе показываются незавершённые истории, закрытые активности и до трёх различных доступных квестовых шагов. Уведомление откладывается на время боя/кат-сцены/подземелья. Каталог загружается в фоне, состояние игры читается на Framework-потоке раз в три секунды. Сетевых запросов и аккаунта сайта не требуется. Интерфейс русский/английский; названия квестов и контента английские.

## Сборка и локальная установка

Для установки релиза добавьте общий репозиторий в `/xlsettings` → Experimental → Custom Plugin Repositories:

```text
https://raw.githubusercontent.com/karkandcoypp/FFXIV-Dalamud-Plugins/main/pluginmaster.json
```

Затем найдите **Eorzea Compass** в `/xlplugins`, установите и откройте `/compass`. Если общий репозиторий уже подключён, достаточно обновить список плагинов. Ниже — инструкции для самостоятельной сборки.

Нужны .NET 10 SDK, Dalamud API 15 и библиотеки из `%APPDATA%/XIVLauncher/addon/Hooks/dev` (или `DALAMUD_HOME`).

```powershell
./build.ps1 -Plugin EorzeaCompass
dotnet run --project EorzeaCompass/tests/CompassChecks/CompassChecks.csproj -c Release
```

Путь к DLL после сборки: `EorzeaCompass/EorzeaCompass/bin/Release/EorzeaCompass.dll`. Добавьте его в `/xlsettings` → Experimental → Dev Plugin Locations, затем загрузите плагин через Dev Tools в `/xlplugins`. Откройте `/compass`.

Проверка каталога на локальных игровых файлах (без запуска игры):

```powershell
dotnet run --project EorzeaCompass/tests/CompassChecks/CompassChecks.csproj -c Release -- "C:/path/to/FINAL FANTASY XIV Online/game/sqpack" "catalog-audit.json"
```

Тесты проверяют дерево требований, альтернативы, неизвестные условия, историю и отдельные состояния открытия/прохождения; с игровыми файлами дополнительно проверяются охват каталога и известные цепочки ARR–Stormblood.

## Проверка в игре перед выпуском

1. Сопоставить открытые и закрытые активности с Duty Finder на реальном персонаже, включая первое прохождение.
2. Проверить NPC и координаты для новой цепочки Crystal Tower, Alexander или Ivalice.
3. Принять квест, отменить, перезайти: проверить сохранённый статус «В процессе».
4. Сменить персонажа: исключить перенос истории и скрытых активностей.
5. Проверить уведомление один раз при входе, задержку в бою/кат-сцене и отключение в настройках.

Сборка и проверки файлов не заменяют эти игровые проверки.
