# Eorzea Compass — 0.2.1

Навигатор по неоткрытому контенту персонажа для Dalamud API 15. Команда: `/compass`.

Слева находится постоянное меню: «Ещё не открыто», «Продолжить», «Уже открыто», «Весь контент» и категории активностей. В центре — список с кратким статусом, справа — выбранная активность и блок «Что сделать дальше». Для доступного задания указаны NPC, место и кнопка карты. Если текущая профессия не подходит, показаны подходящие прокачанные классы персонажа. Поиск и дополнение находятся над списком; сложные версии и скрытые активности — в «Ещё фильтры». Готовые к началу активности стоят первыми. Технические сведения спрятаны в раскрывающиеся блоки.

Окно использует непрозрачный фон и увеличенные отступы. При смене фильтров справа всегда показывается активность из текущего списка. Ориентиры дизайна и ссылки на референсы: [UI-REFERENCES.md](UI-REFERENCES.md).

Каталог строится из `ContentFinderCondition` и полного индекса `Quest` установленной игры. Для статусов используется `IUnlockState.IsInstanceContentUnlocked`; первое прохождение проверяется отдельно через `UIState.IsInstanceContentCompleted`. Достижения не требуются. «Пройдено» означает первый клир конкретного боя/подземелья, а не 100% наград или завершение всех квестов сюжетной линии.

Квесты связываются по `Quest.InstanceContentUnlock` или основному параметру `INSTANCEDUNGEON0`. Старые квесты без JournalGenre исключаются из связей. Параметры `INSTANCEDUNGEON1` и далее могут содержать посторонние упоминания: они используются только при отсутствии основной связи, совпадении дополнения/уровня и принадлежности к сюжетному разделу либо наличии признака открытия в интерфейсе квеста. В карточке указан источник связи; упоминание в скрипте не гарантирует точный момент открытия. Если маршрут неоднозначен или не найден, статус активности всё равно виден, но рекомендация не выдаётся.

Следующий шаг ищется в дереве предыдущих квестов с учётом AND/OR, выполненных и принятых заданий, текущего класса и уровня. Неизвестные операторы, ограничения по стадии квеста и дополнительные условия не считаются подтверждённым доступом. Для принятых заданий нужно следовать игровому журналу; кнопка начального NPC намеренно показывается только для непринятого задания. Координаты выдачи проверяются по Level, объекту NPC и карте.

«В процессе» определяется по принятому связанному квесту, сохранённой истории или выполненным/принятым предшествующим квестам **той же** линии Chronicles of a New Era. Общий выполненный MSQ не превращает все будущие активности в начатые. Плагин запоминает такие наблюдения раздельно для персонажей. Восстановить факт принятия и отмены задания до установки, если игра не оставила других признаков, невозможно.

При входе плагин ждёт загрузки персонажа, затем один раз показывает число закрытых активностей и до трёх различных доступных квестовых шагов. Уведомления откладываются на время боя, кат-сцены и подземелья. Настройки позволяют отключить сообщения или включить автоматическое открытие окна. Каталог загружается в фоновом потоке; чтение состояния игры выполняется на потоке Framework, раз в три секунды. Сетевых запросов нет.

Интерфейс русский/английский; названия контента, NPC и квестов на английском. Класс и уровень оцениваются для **текущей профессии**. Владение дополнением, доступность входа на сервере и все особые условия игра может проверять отдельно. Полного покрытия всех типов активностей в этой версии нет: реликты, исследовательские зоны, профессии и остальные категории отложены.

## Сборка и локальная установка

Для установки релиза добавьте общий репозиторий в `/xlsettings` → Experimental → Custom Plugin Repositories:

```text
https://raw.githubusercontent.com/karkandcoypp/FFXIV-Dalamud-Plugins/main/pluginmaster.json
```

Затем найдите **Eorzea Compass** в `/xlplugins`, установите и откройте `/compass`. Если общий репозиторий уже подключён, достаточно обновить список плагинов. Ниже — инструкции для самостоятельной сборки.

Нужны .NET 10 SDK, Dalamud API 15 и библиотеки из `%APPDATA%/XIVLauncher/addon/Hooks/dev` (или `DALAMUD_HOME`).

```powershell
./build.ps1 -Plugin EorzeaCompass
dotnet run --project EorzeaCompass/tests/CompassChecks/CompassChecks.csproj -c Release
```

Путь к DLL после сборки: `EorzeaCompass/EorzeaCompass/bin/Release/EorzeaCompass.dll`. Добавьте его в `/xlsettings` → Experimental → Dev Plugin Locations, затем загрузите плагин через Dev Tools в `/xlplugins`. Откройте `/compass`.

Проверка каталога на локальных игровых файлах (без запуска игры):

```powershell
dotnet run --project EorzeaCompass/tests/CompassChecks/CompassChecks.csproj -c Release -- "C:/path/to/FINAL FANTASY XIV Online/game/sqpack" "catalog-audit.json"
```

Тесты проверяют дерево требований, альтернативы, неизвестные условия, историю и отдельные состояния открытия/прохождения; с игровыми файлами дополнительно проверяются охват каталога и известные цепочки ARR–Stormblood.

## Проверка в игре перед выпуском

1. Сопоставить открытые и закрытые активности с Duty Finder на реальном персонаже, включая первое прохождение.
2. Проверить NPC и координаты для новой цепочки Crystal Tower, Alexander или Ivalice.
3. Принять квест, отменить, перезайти: проверить сохранённый статус «В процессе».
4. Сменить персонажа: исключить перенос истории и скрытых активностей.
5. Проверить уведомление один раз при входе, задержку в бою/кат-сцене и отключение в настройках.

Сборка и проверки файлов не заменяют эти игровые проверки.
