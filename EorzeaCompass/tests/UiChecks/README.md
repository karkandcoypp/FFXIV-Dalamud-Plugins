# Проверка компактного интерфейса

Windows, .NET 10 и локальные библиотеки Dalamud API 15. Сначала собрать плагин в Release.

```powershell
dotnet run --project EorzeaCompass/tests/UiChecks/UiChecks.csproj -- "C:/path/to/game/sqpack" "ui-review"
python EorzeaCompass/tests/UiChecks/render.py ui-review
```

Для Python нужны numpy и Pillow. Результаты пишутся в указанную выходную папку, в репозиторий их добавлять не нужно.

Стенд вызывает настоящие `DrawNavigation`, `DrawRow`, `DrawDetail` и `CompassTheme` в отдельном контексте ImGui. Состояние персонажа и NPC заменены тестовыми данными. Верхняя панель фильтров воспроизведена статическими элементами: ввод текста требует инициализации окружения Dalamud и здесь не тестируется. Это проверка панелей, не скриншот работающей FFXIV.

14 сценариев: стандартный размер, минимальный размер, увеличенный текст, длинное название, принятое задание, неподходящий класс, английский язык; обзор при трёх размерах; незавершённая история при двух размерах, завершённая история и неизвестный статус. Каждый рисуется три кадра. Проверяется компактность строк и отсутствие переполнения карточки. Буферы ImGui сохраняются в JSON, затем программный растеризатор строит PNG для визуальной проверки. Сглаживание шрифта и заголовок окна могут отличаться от игрового окружения.

Статические заглушки фильтров не проверяют их клики. Поведение выбора после фильтрации отдельно проверяется в CompassChecks. Изменение состояния реального персонажа и открытие карты нужно проверять в игре.
