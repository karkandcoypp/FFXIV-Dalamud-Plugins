# Проверка интерфейса 0.2.1

Перед публикацией выполнено:

- Release-сборка с `--warnaserror`: без предупреждений и ошибок.
- Алгоритмические проверки прогресса и выбора активности: 26 успешных проверок.
- Семь сценариев отрисовки на стенде `tests/UiChecks`, по три кадра: 1180×760, 960×600, 1440×900 с увеличенным текстом, длинное название, принятое задание, неподходящий класс и английский язык.
- Карточки и навигация рисуются производственными методами; верхние элементы фильтров заменены статическими заглушками. Тестовые данные не являются прогрессом реального персонажа.
- Проверены изображения обычной, минимальной, увеличенной, длинной карточки и состояния другого класса. Основное действие и закрытые дополнительные блоки помещаются в проверенных размерах; у минимального размера остаётся запас по высоте.
- Яркость выделения уменьшена, заполненные блоки дополнительных сведений сделаны нейтральными. Основной акцент остаётся на статусе и действии.

Стенд не заменяет проверку окна в игре с пользовательским шрифтом, локализацией и реальным прогрессом. Код воспроизводимых проверок находится в `tests/UiChecks`; PNG создаются локально.
