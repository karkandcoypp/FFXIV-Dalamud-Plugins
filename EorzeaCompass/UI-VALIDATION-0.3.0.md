# Проверки журнала 0.3.0

## Расчёт прогресса

492 проверки с игровыми файлами: регрессия активностей, состояния историй, явное завершение финальным квестом, отличие первого клира от конца сюжета, неизвестные данные, история принятия и альтернативные ветки (включая активное задание внутри ветки).

Все 37 записей `config/stories.json` сверены с установленным Quest: ID, название и JournalGenre финального задания. Проверены начало маршрута без прогресса и завершение по каждому финальному квесту. Ivalice и Crystal Tower используют сюжетные окончания, а не дополнительные задания после них.

Каталог собран независимо из игровых данных. XIV ToDo используется как ориентир структуры разделов; его код и база не включены.

## Отрисовка

Стенд UiChecks использует производственные методы навигации, обзора, строк и карточек. 14 сценариев по три кадра: обычное/минимальное окно, увеличенный текст, длинное название, принятое задание, другой класс, английский язык; обзор при трёх размерах; незавершённая история при двух размерах, завершённая история и неизвестный статус.

Ввод текста и строка фильтров заменены статическими заглушками, как описано в README стенда. Персонаж и NPC тестовые. Изображения просмотрены вручную, проверяется отсутствие переполнения основных карточек; обзор в маленьком окне допускает обычную вертикальную прокрутку.

Сборка Release выполняется с предупреждениями как ошибками. Проверки отрисовки не подтверждают работу ввода, карты или состояния персонажа внутри запущенной FFXIV — это нужно проверить в игре.
