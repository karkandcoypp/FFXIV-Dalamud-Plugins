# Проверка VendorProfit 0.1.0.0

- Сборка Release, Dalamud API 15 / .NET 10: 0 ошибок, 0 предупреждений (`--warnaserror`).
- 31 локальная проверка: арифметика полных стаков и налога на примерах пользователя, HQ, неверные и неполные данные, временные метки, сопоставление строк после сортировки/переработки, неоднозначные NQ/HQ, 429 и частичный отказ пакета.
- 3 ограниченные живые HTTP-проверки через **тот же C# MarketClient**, без игры и покупок: `aggregated/80/8144`, `80/8144?listings=3&entries=0`, `80/8144,8142?listings=3&entries=0`. Все прошли. Изолированная среда не разрешала DNS; проверка выполнена с сетевым доступом вне sandbox.
- 2 проверки нового выпуска: сохранение других записей ленты / правильный тег; отсутствие вызовов покупки и записи в игровые UI-узлы.
- 8 общих проверок публикации прошли. Для тестов временных локальных Git-репозиториев потребовалось исполнение вне sandbox из-за запрета MSYS.
- ZIP, CRC, DLL, манифест, API и соглашение версии/тега проверены общим `tools/verify_release.py`. SHA256 находится в `artifacts/VendorProfit.zip.sha256`.
- Проверка упаковки выполнялась с временным каталогом в рабочей папке, поскольку sandbox блокировал создание файлов в назначенном системном Temp.

Не проверены: загрузка DLL в запущенном клиенте FFXIV, реальное совпадение/позиция рамок при разных масштабах и форматах UI, прокрутка, сортировка, покупка одного пробного стака и фактическая продажа NPC. Полный производственный проход фонового каталога новым C# клиентом не запускался; проверены его ограниченные запросы и поведение на модельном частичном отказе.

Публичный тег, GitHub Actions и запись общей ленты ещё не опубликованы. Подготовлен workflow `vendorprofit-release.yml`, тег `vp-v0.1.0`. Личные настройки и изменения CraftProfile не входят в этот выпуск.
