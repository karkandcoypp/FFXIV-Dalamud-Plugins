# VendorProfit 0.1.0 — предварительная версия

При открытии Market Board показывает кандидатов на покупку целыми стаками с последующей продажей обычному NPC. `/vendorprofit` открывает окно вручную. По умолчанию порог — 1 000 гил чистой прибыли за лот, настраивается до 1 гил. Доход в час не прогнозируется: время поиска и доступный объём неизвестны.

## Работа

- Текущий **посещаемый** мир, не домашний мир персонажа. Поездки и покупки плагин не выполняет.
- Фоновая проверка Universalis при открытии, повтор не чаще 20 минут; кнопки обновления и остановки. Каталог из локальных таблиц игры, до 100 предметов за агрегированный запрос, последовательные запросы с паузой 300 мс, максимум 300 кандидатов/15 запросов лотов, дедлайн 10 минут, ограниченные повторы и `Retry-After`. После трёх подряд отказавших пакетов проверка каталога прекращается. Счётчики ошибок и неизвестных сохраняются в результате.
- Кандидаты из Universalis **предварительные**, возраст виден. Поиск через агрегаты и ограниченные книги не является полным сканированием рынка и не гарантирует наличие лота. Неизвестная/отсутствующая цена не равна нулю. По нажатию копируется название для обычного поиска Market Board.
- Для открытого предмета реальные цены/количества/налог из `IMarketBoard.OfferingsReceived` сверяются с текущим `InfoProxyItemSearch`. Не подтверждённые или старше двух минут предложения исключаются; для повторной проверки обновите игровую выдачу.
- Зелёная рамка рисуется поверх **видимой строки**, только если подтверждена вся текущая книга и однозначно совпали ретейнер, количество и полная стоимость. Порядок пакетов не считается порядком строк. При неоднозначности, загрузке, несовпадении предмета, неполных пакетах или закрытии подсветки нет. Рамка не меняет игровые узлы и не блокирует клики. Если формат строк отличается от поддержанного, таблица остаётся доступной, а рамка не рисуется.
- При смене сервера/выходе результаты сбрасываются, запрос отменяется. Персональные данные на сервер не отправляются: Universalis получает только world ID и item ID, как при обычном запросе рынка.

## Контракт расчёта

`Покупка = цена единицы × количество + налог за стак`.

`Выручка = цена продажи NPC за единицу × количество`.

`Прибыль = выручка − покупка`. Налог продавца Market Board здесь не участвует, поскольку продажа производится NPC. Живые предложения используют переданный игрой `TotalTax` ровно один раз. У Universalis `pricePerUnit`/`total` без покупательского налога; используется `tax`, а при отсутствии явно показывается оценка `floor(total × 0.05)`.

NQ: `Item.PriceLow`; HQ: `ceil(PriceLow × 1.1)`. Нулевые цены, невозможные HQ, неверные количества, манекены и комплекты исключаются. У экипировки цена зависит от состояния: в живой выдаче принимается только полное состояние 30000. Universalis не сообщает состояние, поэтому фоновый поиск экипировку исключает. Бонус Doman Enclave не учитывается.

Проверочные примеры из Market Board: Clear Demimateria III 3 × 4532 + 679 налог = 14275; NPC 15000; прибыль 725. Лот 2 × 4771 + 477 = 10019 даёт **убыток 19**. Dinosaur Fossil 99 × 35 + 173 = 3638; NPC 5841; прибыль 2203.

Источники структуры: [Universalis API](https://docs.universalis.app/), [InfoProxyItemSearch](https://github.com/aers/FFXIVClientStructs/blob/main/FFXIVClientStructs/FFXIV/Client/UI/Info/InfoProxyItemSearch.cs), [AtkComponentList](https://github.com/aers/FFXIVClientStructs/blob/main/FFXIVClientStructs/FFXIV/Component/GUI/AtkComponentList.cs).

## Сборка и установка

`.NET 10`, Dalamud API 15. `./VendorProfit/build.ps1` собирает, запускает регрессии и проверяет ZIP. Для локальной сборки без доступа к NuGet Audit: `./VendorProfit/build.ps1 -Offline` (CI использует обычный режим).

Архив: `VendorProfit/artifacts/VendorProfit.zip`. Для ручной проверки распаковать ZIP в отдельную папку и добавить абсолютный путь DLL в Dev Plugin Locations. Не включать одновременно локальную и опубликованную копии.

Публикация через тег `vp-v0.1.0` и общий `pluginmaster.json`. Ветка workflow_dispatch выполняет только проверку, без выпуска. После успешного workflow добавьте в Custom Plugin Repositories адрес `https://raw.githubusercontent.com/karkandcoypp/FFXIV-Dalamud-Plugins/main/pluginmaster.json`, обновите `/xlplugins` и установите VendorProfit.

## Проверка в игре перед массовыми покупками

Сборка, тесты и HTTP-проверка не подтверждают отрисовку в клиенте. Проверить открытие/закрытие Market Board, изменение сортировки, прокрутку, масштаб UI, одинаковые NQ/HQ лоты, обновление выдачи после покупки, отмену и смену мира. Сверить Total в окне подтверждения и фактическую выручку обычного NPC на одном дешёвом стаке. Автоматических покупок нет.
